# Quick Form Fill · 快速填表

Chrome / Edge → 扩展程序 → 开发者模式 → 加载此目录。

先保存填表资料，然后在“GPT 设置”配置自己的 OpenAI API key，即可扫描任意普通表单并做语义匹配。不配置 key 也可以使用规则与手动匹配。

默认模型为 GPT-6 Luna，插件免费，API 用量由用户的 OpenAI 账户支付。Key 默认仅保留到浏览器会话结束，可显式选择未加密的本地长期保存。资料值不发送给模型；字段描述和资料名称会发送到 OpenAI。填入前须核对，不自动提交。

项目完整安装说明、费用与隐私边界见项目根目录 README.md。
